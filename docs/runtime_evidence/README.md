# MoveNet runtime evidence

These artifacts were generated by running the repository's actual MoveNet ONNX pipeline against the committed Wikimedia Commons squat sample. The source is public CC BY 3.0 media attributed to FitnessScape; it is not customer or clinical data.

Run from the repository root:

```powershell
py scripts/models/download_movenet.py --output models/movenet-singlepose-lightning.onnx
py scripts/datasets/download_wikimedia_squat.py
py scripts/verification/generate_movenet_runtime_evidence.py
```

The script decodes all source frames, samples at 4 FPS for inference, runs MoveNet SinglePose Lightning through ONNX Runtime's CPU provider, computes the existing squat analytics, and encodes every source frame into the annotated MP4. The overlay is generated by `packages/pose_core/processing.py`; it is not a manually annotated screenshot.

Artifacts:

- `movenet-squat-runtime.mp4`: source-resolution annotated animation; sampled frames contain model landmarks and unsampled frames remain source pixels.
- `movenet-squat-runtime-poster.jpg`: first model-annotated frame emitted by the same run.
- `movenet-squat-runtime-trace.csv`: one row per valid sampled pose with frame, timestamp, track, confidence, landmark count, and normalized bounding box.
- `movenet-squat-pose-sequence.json.gz`: compressed pose sequence emitted by the processing pipeline.
- `movenet-squat-runtime-summary.json`: source/model hashes, runtime versions, measured counts, artifact hashes, and the exact claim boundary.

The model is intentionally not committed. Its expected SHA-256 is pinned in `scripts/models/download_movenet.py` and is recorded again in the runtime summary.
